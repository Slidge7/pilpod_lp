Architecture

Built for the Power User.
Engineered for the Long Haul.

PilPod doesn't just wrap the Web Audio API. It speaks the browser's native language — lifecycle events, service workers, and direct keypress simulation.

TabRegistry & Service Worker
A persistent service worker maintains a live registry of all open tabs, consuming chrome.tabs lifecycle events in real-time. No polling. No stale state. Every tab creation, update, and removal is captured instantly and surfaced to the popup with zero latency.
chrome.tabs API · Service Worker
Auto-Discard Protection
Chrome's aggressive tab discarding can silently freeze background audio streams. PilPod marks any tab with active media as non-discardable via autoDiscardable: false, ensuring your music keeps playing even when the browser's memory pressure spikes to critical.
Memory Management · Auto-Discard
Self-Healing Content Scripts
Under memory pressure, Chrome can silently terminate injected content scripts without notification. PilPod's service worker runs periodic health checks and silently re-injects scripts into any tab that fails a ping — zero UI disruption, zero user intervention required.
Self-Healing · Script Re-injection
Native Player Bridging
Rather than hacking the Web Audio graph, PilPod simulates the exact keyboard events native players expect — pitch-correct volume steps, seek commands, playback toggles — delivering lossless precision control across YouTube, Spotify Web, SoundCloud, and any HTML5 player.
KeyboardEvent · Web Audio API
